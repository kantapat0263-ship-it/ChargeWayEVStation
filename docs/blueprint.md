# **App Name**: ChargeWay ATTO3

## Core Features:

- Route & Battery Input: Allow users to input their origin, destination, current battery percentage, and desired stop-charging percentage for trip planning.
- Intelligent Charging Stop Calculation: Calculate optimal charging stop locations along the route based on BYD ATTO3's estimated range (~400km per full charge) and user-defined battery parameters.
- EV Charging Station Discovery: Utilize the Google Places API to search for relevant EV charging stations in proximity to the calculated charging stop zones.
- Charging Network Filtering: Enable users to filter the discovered charging stations by specific networks (e.g., PTT EV Station, PEA Volta, ELEXA).
- Interactive Route Map Display: Present the planned route on an interactive Google Maps interface, prominently displaying origin, destination, calculated charging stop markers, and nearby charging stations, which remain visible throughout the planning process.
- Seamless Google Maps Navigation Launch: Provide a 'Start Navigation' button that opens the Google Maps mobile application directly, pre-populated with the planned route and all charging waypoints.

## Style Guidelines:

- The concept revolves around efficiency, electric mobility, and journey planning, suggesting a clean, modern aesthetic. A light color scheme is most appropriate. The primary color is a calming yet clear medium blue (#4080BF), chosen for its association with trust, technology, and open skies. The background color is a heavily desaturated variant of the primary hue (#EEF4F8), providing a subtle, clean canvas. The accent color, a vibrant blue-green (#1F8C8C), is analogous to the primary and offers a refreshing contrast for interactive elements and highlights.
- Body and headline font: 'Inter', a grotesque-style sans-serif for its modern, objective, and highly legible characteristics, suitable for conveying technical information and route details clearly.
- Employ a set of clear, minimalist vector icons to represent battery levels, charging stations, and navigation actions, ensuring visual clarity and modernity.
- Utilize a clean, organized layout with a distinct division between user input forms, search results, and the interactive map display, prioritizing user focus and ease of use.
- Incorporate subtle and smooth transitions for map panning, zooming, and when applying filters, enhancing the user experience without being distracting.
